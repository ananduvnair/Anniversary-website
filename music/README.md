# 🎵 Music Folder

Drop your anniversary background music here!

### How to use:

1. **Option A (Quickest)**:
   - Rename your song file to **`song.mp3`**
   - Place it directly in this `music/` folder:
     `d:\our anivessary\music\song.mp3`
   - Refresh `index.html` in your browser. Done!

2. **Option B (Any filename / format)**:
   - Drop your song here with any name (e.g. `Our_Song.mp3`, `love.m4a`, `track.wav`)
   - Run in terminal:
     ```powershell
     node setup.js
     ```
   - It will automatically detect your audio file and connect it!

Supported formats: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.flac`, `.aac`.
