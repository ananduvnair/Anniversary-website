# 📸 Photos Folder

Drop your photos here with these exact names:

```
photo01.jpg
photo02.jpg
...
photo20.jpg
```

Or edit `photos.js` in the root folder to point to any filenames you want.

## Tips
- Recommended size: **800×800 px** or larger square/portrait crops work best
- Format: JPG, PNG, or WebP all work
- If a photo is missing, the tile shows a beautiful blue placeholder automatically

## Captions
Open `photos.js` and edit the `caption` text for each entry to personalize
the message shown when you click that photo in the lightbox.
