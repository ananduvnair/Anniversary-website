# 💖 Anniversary Website

A romantic, interactive website to celebrate a special anniversary, with heartfelt messages, memories, and a touch of animation.

🔗 **Live Demo:** [Add your link here](#)

---

## ✨ Features

- 💌 Personalized love message
- 📸 Photo gallery of favorite memories
- 🕰️ Timeline of your journey together
- 🎵 Background music
- 🎉 Smooth animations and surprise effects
- 📱 Fully responsive (mobile, tablet, desktop)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ananduvnair/Anniversary-website.git
cd Anniversary-website
```

### Run locally

Open `index.html` in your browser, or use a local server:

```bash
# using VS Code Live Server, or
npx serve .
```

## 🎨 Customization

1. Replace the images in the `images/` folder with your own photos.
2. Edit the messages and dates in `index.html`.
3. Swap the music file in `audio/` for your favorite song.
4. Change colors and fonts in `css/style.css`.
